# このディレクトリのデータについて

`city.bin.gz`（gzip 圧縮したメッシュ）と `city.json`、および地域ページ用の `<slug>/`（`area.json` とタイル）は、国土交通省 Project PLATEAU の 3D 都市モデルを加工して作成したデータです。

## 出典

- 3D都市モデル（Project PLATEAU）建築物モデル（千代田区）2025年度
  - 配布: G空間情報センター <https://www.geospatial.jp/ckan/dataset/plateau-13101-chiyoda-ku-2025>
  - 使用した範囲: `city.bin.gz` / `city.json`（東京駅周辺）は 3 次メッシュ 53394610 / 53394611 / 53394620 / 53394621 の CityGML（`*_bldg_6697_op.gml`）。`chiyodaku/`（千代田区ページ）は千代田区の建築物 CityGML 全 21 ファイル（38,743 棟）
  - 著作権: 千代田区
  - 利用条件: [PLATEAU サイトポリシー](https://www.mlit.go.jp/plateau/site-policy/)（公共データ利用規約 第1.0版 = PDL1.0 に準拠。CC BY 4.0 互換）
- 3D都市モデル（Project PLATEAU）建築物モデル（名古屋市）2022年度
  - 配布: G空間情報センター <https://www.geospatial.jp/ckan/dataset/plateau-23100-nagoya-shi-2022>
  - 使用した範囲: 名古屋市の建築物 CityGML 全 376 ファイル（`udx/bldg/*_bldg_6697_op.gml`、738,178 棟）
  - 著作権: 名古屋市
  - 利用条件: 同上
  - `nagoya/`（名古屋市ページ）に使用

建物名称など一部の属性は、元データの時点で国土地理院（国土基本情報）や東京都の調査から引用されています。詳しくは上記の配布ページの「出典」を参照してください。

## 加工の内容

上記データを加工して作成しました（`scripts/preprocess/` で再現できます）。

- LOD2 の境界面（屋根・壁・底面）と付属物（lod2Geometry）を三角形に分割。LOD2 の無い建物は LOD1 を使用
- 緯度経度・標高を、東京駅（139.767125, 35.681236）を原点とするローカル座標（メートル）に変換
- 建物ごとに最も低い点を地盤とみなして高さを補正
- 名称・用途・計測高さ・階数・建築年・所在地・建物 ID などの属性を抽出し、PLATEAU で「不明」を表す値（±9999）を除去

地域ページ（`<slug>/`）のデータは次のように加工しました。

- LOD2 を持つ建物も含め、LOD1 の立体から底面の多角形と高さを取り出す（立体はブラウザで押し出して作る）
- 地域ごとの原点（千代田区は東京駅、名古屋市は名古屋駅 136.881537, 35.170915）を基準とするローカル座標に変換し、1024 m 四方のタイルに振り分ける
- 属性は東京駅周辺と同じものを抽出し、タイルごとに gzip 圧縮した JSON に格納

このデータは国土交通省や千代田区・名古屋市が作成・公表したものではありません。内容の正確さについて、加工者・元データの提供者のいずれも保証しません。
