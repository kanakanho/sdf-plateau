# このディレクトリのデータについて

`city.bin.gz`（gzip 圧縮したメッシュ）と `city.json` は、国土交通省 Project PLATEAU の 3D 都市モデルを加工して作成したデータです。

## 出典

- 3D都市モデル（Project PLATEAU）建築物モデル（千代田区）2025年度
  - 配布: G空間情報センター <https://www.geospatial.jp/ckan/dataset/plateau-13101-chiyoda-ku-2025>
  - 使用した範囲: 3 次メッシュ 53394610 / 53394611 / 53394620 / 53394621 の CityGML（`*_bldg_6697_op.gml`）
  - 著作権: 千代田区
  - 利用条件: [PLATEAU サイトポリシー](https://www.mlit.go.jp/plateau/site-policy/)（公共データ利用規約 第1.0版 = PDL1.0 に準拠。CC BY 4.0 互換）

建物名称など一部の属性は、元データの時点で国土地理院（国土基本情報）や東京都の調査から引用されています。詳しくは上記の配布ページの「出典」を参照してください。

## 加工の内容

上記データを加工して作成しました（`scripts/preprocess/` で再現できます）。

- LOD2 の境界面（屋根・壁・底面）と付属物（lod2Geometry）を三角形に分割。LOD2 の無い建物は LOD1 を使用
- 緯度経度・標高を、東京駅（139.767125, 35.681236）を原点とするローカル座標（メートル）に変換
- 建物ごとに最も低い点を地盤とみなして高さを補正
- 名称・用途・計測高さ・階数・建築年・所在地・建物 ID などの属性を抽出し、PLATEAU で「不明」を表す値（±9999）を除去

このデータは国土交通省や千代田区が作成・公表したものではありません。内容の正確さについて、加工者・元データの提供者のいずれも保証しません。
